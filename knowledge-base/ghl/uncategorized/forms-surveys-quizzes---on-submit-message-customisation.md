# Forms, Surveys & Quizzes - On Submit Message Customisation

The On Submit message lets you create branded, accessible confirmation screens for your Forms, Surveys, and Quizzes. This guide covers what it is, why it’s useful, and how to use the editor—so you can deliver polished, on-brand thank-you experiences in minutes.

# **What is the On Submit Message Editor?**

  

The On Submit Message Editor controls what a contact sees immediately after submitting a Form, Survey, or Quiz. Instead of a plain confirmation, you can design a branded message with headings, images, and layout controls that adapt to desktop and mobile.

* * *

## **Key Benefits of the On Submit Message Editor**

  

-   **Richer formatting:** Create headline + subtext with bold, italics, sizes, colors, emojis, links, and images directly inside the editor.  
      
    
-   **Brand consistency:** Align fonts, weights, padding, margins, and corner radius with your visual identity.  
      
    
-   **Background Blur overlay:** Softens busy backgrounds so text remains readable; optionally add a solid/transparent message box color.  
      
    
-   **Device-specific control:** Independently style Desktop and Mobile for optimal readability.  
      
    
-   **Live visual preview:** See changes against your actual background as you edit.  
      
    
-   **Fewer rebuilds:** Design post-submit states without creating separate pages or redirects.

## **How To Customise On Submit Messages**

  

These steps ensure your On Submit message is configured, styled for both devices, and previewed for clarity before you save and publish.

  

1.  Login to your sub-account.  
      
    
2.  Go to **Sites** > **Forms/Surveys/Quizzes** > **Builder**.  
      
    ![](https://jumpshare.com/share/eLLHtJi0Nwvn4C3uBLlm+/GIF+Recording+2025-12-18+at+5.30.07+PM.gif)  
      
    
3.  Click on **\+ Add Form/Survey/Quiz** button to Create a **new** Form/Survey/Quiz or, **Edit** an existing item by clicking the **⋮** (three dots) → **Edit** to open the Builder.  
      
    ![](https://jumpshare.com/share/FJohJIApZsddPtwqyhVA+/Screen+Shot+2025-12-18+at+5.31.37+PM.png)  
      
    
4.  Customize your Form/Survey/Quiz and click **Settings** → **On Submit**.  
      
    
5.  From the dropdown, select **Message**.  
      
    
6.  Use the **rich text editor** to write your headline and subtext.  
      
    
7.  **Apply Text Formatting:** Text size, color/background, alignment, insert bullet or numbered lists, insert links, insert images, and custom values as needed.  
      
    ![](https://jumpshare.com/share/4LUevsy268SyHEWQoS1S+/GIF+Recording+2025-12-18+at+5.42.06+PM.gif)  
      
    
8.  In **Message Styling**: set background color, text weight, and corner radius.  
      
    
9.  Adjust **Margin** and **Padding**.  
      
    
10.  Toggle **Background** **Blur** ON/OFF. (Option is only available when an image is set as background)  
       
     ![](https://jumpshare.com/share/d4888inTYpjNdSgePfEC+/GIF+Recording+2025-12-18+at+6.01.28+PM.gif)  
       
     
11.  Switch between **Desktop** and **Mobile** views.  
       
     ![](https://jumpshare.com/share/7nJj4ZRnb2WqTn1h4wZA+/Screen+Shot+2025-12-18+at+6.04.05+PM.png)  
       
     
12.  Use the **Preview** panel to see how your customisations look like.  
       
     ![](https://jumpshare.com/share/gP0Gaq03j4ywPOIIjE6a+/Screen+Shot+2025-12-18+at+6.00.18+PM.png)  
       
     
13.  After completing customisations, click **Save** in the builder.   
       
     ![](https://jumpshare.com/share/cS06Q9PX94eOdju0eU6w+/Screen+Shot+2025-12-18+at+6.06.11+PM.png)

## **Frequently Asked Questions**

  

**Q. Can I use both a Message and a Redirect at the same time?**

No. Choose one default behavior. Conditional logic can override with a different message or redirect when its conditions match.

  

**Q. Do workflows depend on the On Submit message?**

No. Form/Survey/Quiz Submitted workflows run independently of the visual confirmation.

  

**Q. Images or custom values don’t render in preview. Is that expected?**

Some custom values only resolve on real submissions.
