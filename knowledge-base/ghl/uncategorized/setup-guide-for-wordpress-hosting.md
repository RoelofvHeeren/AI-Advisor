# **What is the WordPress Hosting Setup Guide?**

  

The WordPress Hosting Setup Guide is a built-in onboarding checklist that appears after you subscribe to WordPress hosting. It provides step-by-step tasks, clear CTAs, helpful tooltips, and a progress indicator so you always know what’s done and what’s next. Optional steps can be skipped, and once all tasks are finished, the guide automatically hides to keep your dashboard clean.

* * *

## **Key Benefits of the Setup Guide**

  

Understanding the core advantages helps teams adopt the guide consistently and achieve time-to-value faster. The benefits below map directly to tasks you’ll complete during onboarding.

  

-   **Onboarding clarity:** A guided checklist with CTAs, tooltips, and progress tracking reduces guesswork for new users.  
      
    
-   **Faster time-to-value:** Complete the essential steps in one flow so you can start building, publishing, and measuring sooner.  
      
    
-   **Guided domain & SSL:** Connect a custom domain or confirm a subdomain, then enable SSL for a trusted, secure experience.  
      
    
-   **Safe migration:** Import an existing WordPress site with purpose-built tooling designed to minimize friction.  
      
    
-   **One-click WP Admin access:** Log into your WordPress Admin directly from HighLevel for faster configuration.  
      
    
-   **Built-in security logging:** Enable activity logs to monitor key events and improve visibility.  
      
    
-   **Visibility & progress:** Track completion at a glance; the guide auto-hides when all steps are done.

## **Setup Flow**

  
The seven steps below provide the recommended onboarding flow for WordPress Hosting. Start by creating your site, optionally import an existing site, log in to WP Admin for configuration, connect your domain and enable SSL, turn on activity logs for security visibility, add users with the right roles, and monitor performance and traffic with analytics. Optional items can be skipped at any time, progress is tracked, and the guide auto‑hides after completion.

## **How To Set Up the WordPress Hosting Setup Guide**

  

There’s nothing to install—the guide appears contextually after a new WordPress subscription. Use the paths below to open it based on whether you’ve created a site yet. Proper use ensures you complete essentials in the intended order.

  

**Access paths:**

  
**When no site is created yet (after subscription):**  
  

1.  Go to **Sites → WordPress Dashboard → Setup Guide**.  
      
    
2.  Follow the checklist from **Create Site** onward.  
      
    ![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056793938/original/9eidicTAmdJSyyvavrUmAvOvH6j4U8olpA.png?1761317385)
    

  
  
**For an existing site:**

  

1.  Go to **Sites → WordPress Dashboard → Go to Site → Setup Guide**.  
      
    
2.  Continue remaining steps until completion.  
      
    ![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155056793971/original/t0tRZoNJ37NY3B2X7IaQUl3YYnFjoCKuhQ.png?1761317397)
    

  
  
**Behavior to note**  
  

-   The guide supports skipping optional steps.  
      
    
-   The guide automatically hides after all steps are complete.

## Frequently Asked Questions

  

**Q: Who can access the Setup Guide?**  
Users with permission to manage WordPress Hosting for the location can open and complete the guide.  
  

**Q: Can I skip steps and come back later?**  
Yes. Optional steps can be skipped at any time; you can return to finish remaining steps as needed.

  

**Q: SSL is stuck on “Pending.” What should I do?**  
Confirm your domain points correctly, remove conflicting DNS entries, and try again after DNS propagates.

  

**Q: Does the Setup Guide affect billing or hosting resources?**  
No. The guide is an onboarding experience; it does not change your billing or plan resources.

  

**Q: Can I complete these tasks outside the guide?**  
Yes. All tasks (domains, users, analytics, etc.) are available directly in the WordPress Dashboard—use the guide for convenience and tracking.

  

**Q: Does the guide auto-hide? Can it be shown again?**  
The guide automatically hides after all steps are finished. You can still access each area (Domains, Users, Analytics) from the WordPress Dashboard.
