# **What are Folders for Voice AI Agents?**

  

Folders help you organize Voice AI agents into clear categories inside the agent list and quickly find what you need. This structure makes large deployments easier to navigate and reduces the risk of editing or deleting the wrong agent.

  

Folders are available from **AI Agents** \> **Voice AI** \> **Agent List** and support core operations like create, move, rename, and delete along with bulk operations that make it easy to manage agents and folders at scale.

* * *

## **Key Benefits of Folders for Voice AI Agents**

  

-   **Organization:** Group Voice AI Agents by team, purpose, or phase (demo vs. production).  
      
    
-   **Speed:** Jump straight to the folder that matters instead of scrolling through a single long list.  
      
    
-   **Scale:** Use bulk actions to move or delete many agents/folders in one go.  
      
    
-   **Clarity:** Switch between _Folders First_ or _Agents First_ views to match your task.

## **Manage Folders (Move, Delete, and Edit)**

  

Keep folders current by moving agents, renaming folders or deleting folders you no longer need.

  

  

### **Move an Agent Across Folders**

  

1.  To move an agent into a different folder, click the **3 Dot****(⋮)** icon and select **Move to Different Folder**.  
      
    
2.  Use the **Available Folders** dropdown to choose the destination folder.  
      
    
3.  Once you click **Move Agent**, it will instantly transfer to the selected folder.

  

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060765371/original/q9K0nqXvi7fVNuOTkHQaG3Y0IgdoNhpwRQ.gif?1765916401)

  

  

### **Delete a Folder**

  

If a folder’s no longer needed, delete it by clicking the **3 Dot (⋮)** icon then selecting **Delete**.

  

This only removes the folder, the agents inside return to the main list.

  

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060765081/original/HqVZxWI7a-bVQUpaEyX6jyM449kVdJ8sdw.png?1765916021)

  

  

### **Rename or Edit a Folder**

  

1.  Edit a folder right from the folder view by clicking the **3 Dot (⋮)** icon then selecting **Edit**.  
      
    
2.  Use the **Folder Name** entry to update the name or the **Associate Agents** dropdown to update the agents stored within the folder.

  

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155060765306/original/XAmPvpGA1gvMe4lstT1PWvgOspz6Kj6Ivw.png?1765916292)

## **Frequently Asked Questions**

  

**Q: Can an agent belong to multiple folders?**  
No. An agent can be assigned to one folder at a time.

  

**Q: How many Voice AI agents can I create?**  
Up to **100** agents.

  

**Q: What happens to agents when I delete a folder?**  
Agents are **not** deleted. They’re returned to the main agent list.

  

**Q: Does search work across folders?**  
Search is context-aware. To find agents that live inside a folder, first open that folder and use its search. Searching from the main Agent List does not return agents stored inside folders.

  

**Q: If I create or duplicate an agent while viewing a folder, where does it go?**  
The agent is saved in the **current** (open) folder.
