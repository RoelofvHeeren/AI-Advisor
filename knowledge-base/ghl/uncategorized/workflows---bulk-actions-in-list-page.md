# Workflows - Bulk Actions in List Page

Managing multiple workflows and folders one by one can be tedious. With Bulk Actions, you can select several items directly from the list page and perform common operations in a single step. This article explains how to use bulk actions on the Workflow list page.

# **What is Bulk Actions in Workflow List Page?**

  

Bulk Actions in the Workflows list view let you apply the same commands like Move, Publish/Draft, Delete, or Manage Permissions (folders), to many items at once. This reduces repetitive work, keeps organization consistent, and speeds up day‑to‑day administration for teams that manage dozens or hundreds of workflows.

* * *

## **Key Benefits of Bulk Actions in Workflow List Page**

  

-   **Time savings:** apply the same action to many items at once instead of repeating steps.  
      
    
-   **Consistency:** keep statuses, locations, and permissions aligned across related workflows.  
      
    
-   **Reduced errors:** fewer manual, repetitive clicks lowers the chance of mistakes.  
      
    
-   **Better organization:** move workflows and folders into the right place—including nested folders—in one go.  
      
    
-   **Permission-aware:** actions respect user permissions, ensuring only authorized updates are applied.

* * *

## **How to Use Bulk Actions in Workflows List Page**

  

Follow these steps to perform common bulk operations safely and efficiently. Always review the selected count and confirmation dialog before applying irreversible changes.

  

1.  Login to your sub-account.  
      
    
2.  Go to **Automations** → **Workflows**.  
      
    ![](https://jumpshare.com/share/YLjwmidApgqa2ADnJUCR+/Screen+Shot+2025-11-28+at+5.39.31+PM.png)  
      
    
3.  Apply **filters** or open a **smart** **list** to narrow your results. (Optional)   
    ![](https://jumpshare.com/share/Xg1aYYGwd3bjHH04cnsm+/Screen+Shot+2025-11-28+at+5.42.36+PM.png)  
      
    
4.  Use item **checkboxes** to select **either** **Folders** or **Workflows**.  
      
    
5.  Use **Select All** to choose all visible **Folders** or **Workflows** on the page.  
      
     ![](https://jumpshare.com/share/RQfuAWQC71O7lLLevmqv+/GIF+Recording+2025-11-28+at+5.44.37+PM.gif)  
      
    
6.  Open the **Select All dropdown** to switch between **All Workflows, All Folders, Published Workflows, and Draft Workflows.**  
      
    ![](https://jumpshare.com/share/cx1ewT1Rs7zzdPXfl8qS+/GIF+Recording+2025-11-28+at+5.48.54+PM.gif)  
      
    
7.  From the bulk toolbar, choose an action:  
      
    -   **Publish/Draft** (workflows only)  
          
        
    -   **Move** (workflows or folders)  
          
        
    -   **Delete** (workflows or folders)  
          
        
    -   **Manage Permissions** (folders only)  
          
        
8.  Review the confirmation dialog, which shows how many items will be affected and any warnings.  
      
    ![](https://jumpshare.com/share/zQD8UVJQdCyS9pwiWI7v+/Screen+Shot+2025-11-28+at+5.53.35+PM.png)

## **Availability & Permissions**

  

Bulk Actions respect user roles and existing folder permissions, ensuring only authorized changes are applied.  
  

-   **Where it works:** Available on All Workflows and any smart list you create.  
      
    
-   **Permissions:** Users can only perform bulk actions they’re authorized for. Actions may be hidden or disabled if you lack permission.  
      
    
-   **Scope:** By default, Select All targets the visible items on the current page. When using filters or smart lists, selections reflect the filtered results you can see.  
      
    
-   **Platform:** Designed for the Workflows list page. Behavior may vary on smaller viewports.

## **Frequently Asked Questions**

  

**Q: Is it possible to select Folders and Workflows together?**

No, you can either select Folder(s) or Workflow(s).

  

**Q: Why is Publish/Draft disabled?**

Publish/Draft applies only to workflows. If your selection includes folders or only folders, the option is unavailable. 

  

**Q: Can I update permissions for workflows using Manage Permissions?**

No. Manage Permissions is for folders. Deselect workflows to enable this action.

  

**Q: Does Select All include items beyond the current page?**

Select All targets visible items on the page. Use filters or navigate pages to adjust your selection, or use the dropdown to refine item types.

  

**Q: Can I move items into a folder I can’t access?**

No. You must have access to the destination folder to complete the move.

  

**Q: Will moving items change their permissions?**

After moving, workflows follow the structure and visibility of the destination folder.

  

**Q: Why don’t I see the bulk toolbar?**

The toolbar appears only after you select at least one item. If you still don’t see it, you may not have permission for bulk operations.
