# Error: “This phone number is already registered to a WhatsApp account”

### **What does this error mean?**

This error appears when the phone number you are trying to onboard for WhatsApp (Business or API) is **already connected to an existing WhatsApp account**. A phone number can only be linked to **one WhatsApp account at a time**. Until it is disconnected from the current account, it cannot be used again for onboarding.  
  

### **Why am I seeing this error?**

You may encounter this error for one of the following reasons:

-   The number is currently active on the **WhatsApp mobile app** (personal or business).
    
-   The number is already connected to another **WhatsApp Business Platform** or provider.
    
-   The number was recently disconnected, but WhatsApp is still processing the change.
    
-   The number was previously used for WhatsApp and not fully released yet.
    

  
**How to fix this issue**

Follow the steps below carefully to resolve the error.

#### **Step 1: Disconnect the number from the existing WhatsApp account**

If the number is active on a mobile device:

1.  Open WhatsApp on the phone.
    
2.  Go to **Settings**.
    
3.  Select **Account**.
    
4.  Tap **Delete Account**.
    
5.  Confirm by entering the phone number.
    

> Important: Deleting the account permanently removes chat history and disconnects the number from WhatsApp.

If the number is connected to another provider:

Contact the current WhatsApp provider and request a **full release or deletion** of the number from their WhatsApp Business Platform account.  
  

#### **Step 2: Wait for the number to refresh**

Once the number is disconnected:

-   Wait **up to 3 minutes** for WhatsApp systems to refresh the number’s status.
    
-   In some cases, it may take slightly longer depending on WhatsApp’s backend processing.
    

Do not retry immediately multiple times, as this may cause additional delays.

#### **Step 3: Retry onboarding**

After the waiting period:

1.  Return to the onboarding screen.
    
2.  Re-enter the phone number.
    
3.  Proceed with the verification steps.
    

  
This error is not a system failure. It is a safeguard by WhatsApp to ensure each phone number is uniquely associated with a single account. Once the number is properly disconnected and refreshed, onboarding should complete successfully.
